# InsightHub - 0.7.0

**Open-source Business Intelligence & Data Analytics Platform**

InsightHub is an open-source, browser-based platform for data analysis and business intelligence, designed to bring data preparation, analytical queries, data modeling, calculations, and interactive visualizations together in a unified web experience.

Inspired by tools such as Metabase and Power BI, InsightHub aims to make powerful analytical capabilities more accessible, flexible, and independent of proprietary desktop software.

## Core Capabilities

- **Data Engine** — Manage analytical tables, relationships, measures, aggregations, and filter propagation across related datasets.
- **SQL Query Execution** — Run SQL queries using AlaSQL, with an additional DuckDB-WASM engine and an AlaSQL fallback.
- **ETL & Data Transformation** — Prepare datasets through configurable transformation pipelines, including filtering, column manipulation, type conversion, deduplication, sorting, and calculated columns.
- **DAX-Inspired Calculation Engine** — Evaluate analytical expressions, validate references, and work with measures using a custom implementation of selected DAX concepts.
- **Calculated Columns** — Apply row-level expressions with functions for text, mathematics, dates, conditional logic, and other transformations.
- **Interactive Analytics** — Process data for charts, tables, matrices, KPI cards, gauges, and slicers.
- **Local Project Persistence** — Save project state in the browser, with a local storage fallback.
- **Project Portability** — Export project configurations and analytical models as JSON.

## Project Vision

InsightHub aims to evolve into a flexible, fully web-based BI environment where users can prepare data, build analytical models, define calculations, explore results, and create dashboards without relying on proprietary desktop applications.

The project prioritizes an open and extensible architecture, bringing data engineering and business analytics closer together in a single application.

## Open Source

InsightHub is being developed as an open-source alternative in the business intelligence and analytics ecosystem.

Contributions, suggestions, bug reports, and discussions are welcome.
